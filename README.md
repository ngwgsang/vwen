vwen is still in the kitchen. The data is being curated, the model is being trained, and the GPU fans are sounding like a motorbike on a Hanoi street at rush hour.

### What is it?

vwen is a small language model that rewrites Vietnamese text. The meaning stays the same while the wording changes. Think of it as a friend who can say *"Bạn ăn cơm chưa?"* a dozen different ways without getting bored.

### Why "small"?

Not every job needs a giant model. vwen aims to be light, fast and easy to run on your own machine, with no data center required.
